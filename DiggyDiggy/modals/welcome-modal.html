⛏️ Welcome to Diggy Diggy!

Diggy Diggy is an idle mining game.

Dwarfs go down, Numbers go up!

Getting started:

  • Watch the dwarfs start digging
  • Sell Materials to earn Money
  • Level up your dwarfs
  • Do Reserach, Hire more dwarfs, give them better tools

    • Found a bug or have a suggestion? Let us know on GitHub Issues.

📊 Help improve the game

Every dwarf level(s), we'd like to send anonymous game statistics to help us balance the game. No personal data is collected — only your game progress (depth reached, materials, dwarfs, etc.). You can change this at any time in Settings.
